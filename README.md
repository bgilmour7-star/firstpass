# Firstpass

Practice plans for U7 hockey coaches: curated drills, arranged into stations for three skill groups, used rink-side.

**Now:** the admin drill review screen (`/admin/drills`). **Next:** see `docs/build-plan.md`.

```bash
npm install
npm run dev        # http://localhost:3000, local mode without Supabase
npm run check      # typecheck, lint, tests, drill validation
```

Setup for Supabase and Vercel: `docs/setup.md`. Conventions for people and agents: `CLAUDE.md`.
